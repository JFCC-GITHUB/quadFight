## [1.0.0] – 2026-11-28
First public release. See [RELEASE_NOTES.md](RELEASE_NOTES.md).

### Added
- Desktop builds for Windows (x64), macOS (universal) and Linux (x86-64), plus the Web build; GitHub Actions release workflow with SHA-256 checksums.
- App icon (`.ico` / `.icns` / PNG), generated by `tools/gen_assets.py`.
- English and Traditional Chinese documentation: README, release notes, changelog, privacy policy, third-party notices, licence translation.
- Godot engine licence texts in `licenses/godot/`.
- 2 PLAYERS versus (one computer or tablet), PRACTICE mode, CPU hold and lookahead, skill estimate, fight statistics.
- TOURNAMENT (5 fights + dark-self boss, continues, bonus stage), LADDER, 12 fighters with special attacks and theme songs, CPU Lv 1–20.
- Landscape layouts, rebindable keys, phone/computer control layouts, full-screen button.
- Options: 4 block themes, 3 backgrounds, 2 sound styles, 7 original music styles.

### Changed
- Project settings: ETC2/ASTC texture import enabled (required for the universal macOS export).
- README split into English (`README.md`) and Traditional Chinese (`README.zh-TW.md`).
